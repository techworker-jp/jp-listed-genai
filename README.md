# 国内上場企業の生成AI活用データ

国内の上場企業が生成AIを使っていることを、公開資料から集めたデータです。会社ごとに、生成AIを使っていると分かる公開情報があるかを調べ、出典のURLを付けて載せています。照合を済ませた事例と、業種ごとの数・割合も載せています。運営は株式会社TechWorkerです。

- 更新：毎日（日本時間の朝）
- 最終更新：`data/status.json` の `updatedAt`（データの版）と `lastCheckedAt`（最後に新しい公表を探した日）
- ライセンス：CC BY 4.0（出典を書けば、商用でも加工して使えます）

## 収録の範囲

| ファイル | 中身 | 公開時点（2026年10月20日）の件数 |
| --- | --- | --- |
| `data/companies.csv`・`.json` | 生成AIの活用の公表がある会社。出典のURLつき | 1,487社 |
| `data/cases.csv`・`.json` | 事例。全件を出典の本文と照合済み | 341件 |
| `data/industries.csv`・`.json` | 東証33業種ごとの、調べた会社の数と、公表がある会社の割合 | 33業種 |
| `data/yuho_by_year.csv` | 有価証券報告書を年度ごとに数えた結果 | 4年度 |
| `data/yuho.csv` | 有価証券報告書に生成AI関連の語がある会社と年度。根拠の一文つき | 2,417行 |
| `data/changes/<版>.csv` | 版ごとの、事例の追加・変更・統合・削除 | |
| `data/status.json` | 最終更新日と件数 | |

事例は、建設業と物流（陸運業・海運業・空運業・倉庫・運輸関連業）の会社を全件照合した物と、2026年9月30日から毎日の更新で足した物です。ほかの業種の過去の事例も、照合を済ませた物から足していきます。会社（companies）と業種ごとの割合は、全業種の会社が対象です。

## 数え方

- **公表あり**：その会社が、自社の業務や自社の客への応対で生成AIを使う・試す・使う計画を立てたと分かる公開情報が、1つ以上あること。会社の発表、IR資料、報道、提供会社の導入事例と、有価証券報告書を出典にします。有価証券報告書だけが出典の会社は、その報告書の記載を下の4つで判定し、自社の業務で使う・試す・使う計画と分かる記載がある報告書だけを使います。`companies` には、この会社だけを載せます。生成AIを使った製品を売るだけの会社や、他社の製品の話に語が出るだけの会社は入れません。
- **段階**：公表ありの会社には出典から読み取れるいちばん進んだ段階を付けています。「使っている・導入した」「試している」（実証・試行）「検討・計画」（方針・計画・検討を公表しただけ）の3つです。
- **2つの割合**：`industries` の「公表ありの割合」は3つの段階をすべて数え、「使っている・試しているの割合」は「検討・計画」を除いて数えています。
- **調べた会社**：決まった調べ方で公表を探した会社です。業種の割合の分母は調べた会社で、上場しているすべての会社ではありません。
- **見つからない**：決まった調べ方では公表が見つからなかったことを指します。使っていないという意味ではありません。見つからない会社の名前は載せず、業種ごとの数にだけ入れています。
- **確認中**：以前の調査で公表ありとした会社のうち、出典を今は確かめられない会社です。たとえば、ページが消えた会社や、会社名・生成AIの語がページに見当たらない会社、出典がどれも上の「公表あり」に当たらない会社です。有価証券報告書の「社内で使っている」の記載だけがあり、その記載を判定すると自社の業務での利用に当たらない会社（生成AIを使った製品の研究開発、研究の事業の採択、資産の明細に名前が出るだけ、など）も、ここに入れます。確認中の会社は行を載せず、割合の分母からも外しています。
- **割合の幅**：割合には95%の幅（Wilson の方法）を付けています。調べた会社が30社に満たない業種は「参考」です。順位を付けて比べないでください。
- **初めての公表日**：見つかった出典のうち、いちばん早い日付です。実際に使い始めた時期より遅いことがあります。
- **有価証券報告書**：EDINET の有価証券報告書で、生成AI関連の語（生成AI、ChatGPT、Copilot、Gemini、Claude、LLM、大規模言語モデル、対話型AI、AIエージェントなど）を年度ごとに数えています。「AI」だけでは数えません。語がある報告書は、記載の中身を「社内で使っている」「顧客向けの製品・サービス」「使う方針・検討」などに分けています。

## 作り方と確かめ方

- 事例は、AIが下書きし、出典の本文と項目を1つずつ照らして確かめた物だけを載せます。文章は出典を写さず自分の言葉で書き、出典のページを取れた事例について、出典の文章と20字以上（会社名・製品名などの固有名を除く）同じ部分が無いことを機械で確かめています。
- 会社の出典はページを実際に開き、会社名と生成AI関連の語があることを機械で確かめたうえで、AIがページを読んで段階を判定しています。当たらないと判定した出典は使わず、その会社のほかの出典で同じ確かめをやり直します。
- 抜き取りの確認：判定した会社から100社を無作為に選び、出典を読んで確かめました。公表ありかどうかの誤りは100社中0社、段階の誤りは2社でした（2026年10月20日）。
- 有価証券報告書の記載の分け方は50件を抜き取って読み、48件が一致しました。
- 有価証券報告書だけが出典の会社は、根拠の一文とその前後の本文をAIが読み、会社の出典と同じ4つに分けています。判定した118社から30社を無作為に選んで本文を読み直し、公表ありかどうかの誤りは30社中0社、段階の誤りは1社でした（2026年10月20日）。
- 第三者の株価分析サイトや、AIによる要約サイトは出典にしません。

## 列の説明

### companies.csv（1社1行）

| 列 | 中身 |
| --- | --- |
| 証券コード・会社名・業種・市場 | 東証の上場会社一覧の区分 |
| 段階 | 使っている・導入した／試している／検討・計画 |
| 初めての公表日 | 出典のうち、いちばん早い公表日（YYYY-MM-DD、YYYY-MM、YYYY のどれか） |
| 出典URL・出典の題・出典の公表日 | 複数あるときは「;」でつなぎ、古い順に並べています |
| 確認日 | 出典を最後に確かめた日 |
| 事例の数 | この会社の事例（cases）の数 |
| 有報に社内で使っていると書いた年度 | 有価証券報告書に「社内で使っている」と書いた年度 |

### cases.csv（1事例1行）

| 列 | 中身 |
| --- | --- |
| 事例ID | 「証券コード-連番」。一度振ったIDは変えません |
| 内容の種類 | 活用事例か、全社方針か |
| 事例名・要約・課題・始め方・結果（出典の記載）・注意点 | 出典をもとに書いた文章。効果の数字は、出典にあるとおりに「結果」へ書いています |
| 業務領域・AIの使い方 | （主）が1つ、（すべて）は「;」でつないでいます |
| 対象・展開の範囲・段階 | 社内向けか顧客向けか、どこまで広げたか、どこまで使われているか |
| 提供元・製品名 | 分からないときは「非公表」 |
| 公表日・開始年月 | 公表日は主な出典の日付です。取り組みを始めた年月が分かるときは、開始年月に書いています |
| 出典URL・出典の題・出典の発表元・出典の種類 | 複数あるときは「;」でつないでいます。最初が主な出典です |
| 確認日・初出の版・更新の版 | 照合した日と、その事例が初めて載った版・最後に中身が変わった版 |

### industries.csv（1業種1行）

上場会社数、調べた会社数、公表あり、公表ありの割合（%）と95%の幅（下・上）、使っている・試している（会社数・割合・95%の幅）、参考（調べた会社が30社未満）の列があります。

### yuho_by_year.csv・yuho.csv

`yuho_by_year.csv` には年度ごとに次の3つの数を載せています。有価証券報告書を出した会社の数、生成AI関連の語がある会社の数、「社内で使っている」と書いた会社の数です。`yuho.csv` には、語がある会社と年度ごとに、書類のURL、記載の中身、根拠の一文（報告書からそのまま写した文）を載せています。年度は決算期の末日で決めます（2026年3月期と2025年12月期は、どちらも2025年度）。

JSON は CSV と同じ中身で、複数の値は配列です。CSV は BOM付きの UTF-8 で、Excel でそのまま開けます。

## 使い方の例

Excel：`data/companies.csv` を開いて「挿入 → ピボットテーブル」を選び、行に「業種」、値に「証券コード」の個数を置くと、業種ごとの公表ありの会社数が出ます。

pandas では、次のように読むと業務領域ごとの事例の数が出ます。

```python
import pandas as pd
cases = pd.read_csv("https://raw.githubusercontent.com/techworker-jp/jp-listed-genai/main/data/cases.csv")
print(cases.groupby("業務領域（主）").size().sort_values(ascending=False))
```

## ライセンスと出典の書き方

データは [CC BY 4.0](LICENSE) で公開しています。使うときは、次のように出典を書いてください。

> 出典：TechWorker『国内上場企業の生成AI活用データ』https://github.com/techworker-jp/jp-listed-genai

加工したときは、加工したことも書いてください（例：「…をもとに○○が作成」）。

`yuho.csv`・`yuho_by_year.csv` と、companies の「有報に社内で使っていると書いた年度」、出典URLが EDINET（disclosure2.edinet-fsa.go.jp）の companies の行は、EDINET の有価証券報告書をもとにしています。これらを使うときは、次の出典も書いてください。

> 出典：EDINET（金融庁）の有価証券報告書。TechWorkerが生成AI関連の語の検索、記載の中身の分類と、自社の業務での利用かの判定（AIが分け、根拠の一文が本文にあることを機械で確認）を行い加工（公共データ利用規約 第1.0版）

各事例の文章はTechWorkerが書いたものです。出典のページ（会社の発表・報道など）の著作権は、それぞれの権利者にあります。
